# Shopery Backend API

Node.js, Express, and MongoDB RESTful backend API for the **Shopery** full-stack e-commerce platform.

For complete project documentation, system architecture, API endpoints, demo accounts, and security design, please refer to the master [Root README](../README.md).

## Local Development

```bash
# Install dependencies
npm install

# Seed the database
node seed.js

# Start development server on http://localhost:5000
npm run dev
```
