# Shopery Frontend

React 18 + Vite frontend client for the **Shopery** full-stack e-commerce platform.

For complete project documentation, system architecture, API specifications, and setup instructions, please refer to the master [Root README](../README.md).

## Local Development

```bash
# Install dependencies
npm install

# Start development server on http://localhost:5173
npm run dev

# Build for production
npm run build
```
